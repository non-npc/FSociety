fsociety client - Open Beta
================================

Run fsociety.exe. The application is portable and stores each Nostr identity's
encrypted vault, SQLite state, settings, and downloaded attachments in the
data subfolder beside fsociety.exe. Keep the entire folder together when moving
it. No administrator privileges or central fsociety server are required.

Windows may show a reputation warning for unsigned beta executables. Verify the
fsociety.exe SHA-256 value against SHA256SUMS.txt before running the application.

Back up your Nostr recovery secret. fsociety cannot recover a lost secret or
vault password.
